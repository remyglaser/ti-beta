Search function

Input: find out standard TI input routine?

Options:
* Whole word
* In one plugin
* max # of results
* Case sensitive

Implementation of options:
Whole word:
If the prefix and suffix of a result are delimiter chars, then the result is a whole word

In one plugin:
The specific plugin will be selected in the main menu; just don't search outside the plugin;)

Max # of results:
Will be used as loop counter. Set to 255 if not user specified

Case sensitive:
Compare each alphabetic char 2 times: uppercase and lowercase (whoa double search time)

Result List:
Display list of plugins or result context (like google:-))?
in case of context->multiple pages-> needs memory-> allocate via OS?
Needs a cursor to scroll through the results
Select a result-> go to the right page of the plugin

00 |2 Results in [plugin name]:

Storage:
[number of plugins with results n] [plugin entry 1] [plugin entry 2] ... [plugin entry n]

Plugin Entry:
[plugin name]** [number of results n] [result entry 1] [result entry 2] ... [result entry n]

Result Entry:
[Page in plugin] [00]* [result context] [00]

* [00] at both sides of the variable length context; The result list can be processed downwards and upwards
** The plugin adress can be derived from its name



Search algorithm:

Primary Loop: uses _FindBetaDown to go through the plugin list (this loop is obsolete if only searching in one plugin!)
	Plugin Name is stored (but not in the result list, because we don't know if this one contains results)
	A flag tells if there are any results in this plugin

	Secondary Loop: loops through each character of the plugin
		keep track of the page #!
		also keep track of the last newline adress (for contexts sake!)
		use standard asm multi-letter string search algorithm, optional check for case sensitive zut
		Check if it is a whol word (optional of course)
		If a result is found && it is the first one
			increase number of plugins with results
			Set the flag
		If a result is found (in general)
			increase number of results in this plugin-> Check if the results do not exeed the max # of results!
			add a result entry to the list
